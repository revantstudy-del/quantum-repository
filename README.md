# Hybrid Quantum Circuit Simulator (Python & NumPy)

A state-vector quantum circuit simulator built from scratch using Python and NumPy for the Phoenix Association IT Team Induction (2026–27). This project models multi-qubit systems, single/two-qubit gate operations, state measurement sampling, performance KPIs, and FPGA hardware scaling analysis.

---

## 1. Project Structure

* `simulator.py` — Core quantum simulator (`QuantumState`), single/multi-qubit gate transformations ($I, H, X, Z, \text{CNOT}$), and Bell State execution.
* `benchmark.py` — KPI benchmarking suite (measuring execution time, memory scaling, and probability normalization across 1–12 qubits).
* `failure_test.py` — Failure analysis scripts for floating-point precision drift and memory allocation limits.
* `kpi_benchmark_plots.png` — Visual performance graphs generated by `benchmark.py`.
* `REPORT.md` — Comprehensive technical report detailing quantum linear algebra, KPI results, FPGA hardware acceleration, failure analysis, and optimization strategies.
